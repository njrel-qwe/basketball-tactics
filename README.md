# Тактика Баскет — тактический планшет тренера

Баскетбольная площадка на экране телефона: расставляйте игроков, рисуйте комбинации по шагам
и проигрывайте их анимацией. Основная версия — **сайт-приложение (PWA)**, работает на iPhone и Android.

## Установка на телефон

Откройте адрес сайта (GitHub Pages этого репозитория) и добавьте его на главный экран:

- **iPhone (Safari):** «Поделиться» ⬆︎ → «На экран „Домой“» → «Добавить».
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».

После этого приложение открывается с иконки во весь экран и работает без интернета.
Тактики хранятся на самом телефоне. Чтобы передать тактику другому человеку, используйте
«Отправить ссылкой» (тактика целиком закодирована в ссылке) или файл `.json`.
Для страховки делайте «Резервную копию всех тактик» из меню ⋮ на главном экране.

## Возможности

- Площадка FIBA: вся или половина. Поле занимает весь экран, все кнопки внизу —
  удобно придумывать комбинацию прямо при игроках. Если повернуть телефон горизонтально,
  площадка ложится боком (можно закрепить положение: ⋯ → «Положение поля»).
- Свои игроки (синие) и соперники (красные), мяч «прилипает» к игроку.
- Линии: бег (стрелка), ведение (волна), передача (пунктир), заслон (Т-образная), от руки или прямые.
- Отмена/повтор, ластик, очистка шага или всей схемы.
- Шаги комбинации: «+ Шаг» переставляет игроков в концы их стрелок и передаёт мяч адресату паса;
  комментарий к каждому шагу.
- Воспроизведение ▶ по траекториям, ⏮ ⏭ по шагам, скорость 0.5× / 1× / 2×.
- Сохранение анимации в видео (MP4 на iPhone) — ⋯ → «Сохранить видео».
- Несколько вариантов одной комбинации.
- Картинка шага или всех шагов на одном листе (через меню «Поделиться» → «Сохранить изображение»).
- Справочник: пик-н-ролл, пик-н-поп, отдай-и-выйди, выход из-под заслона, бэкдор,
  атака против зоны 2-3, хорнс — с анимацией и объяснениями, можно скопировать к себе.

### Управление на телефоне

| Действие | Как |
|---|---|
| Переместить игрока / мяч | Инструмент «Двигать», перетащить пальцем |
| Нарисовать линию | Выбрать «Бег», «Ведение», «Пас» или «Заслон» и провести от игрока |
| Номер, мяч, удаление игрока | Удерживать палец на игроке |
| Добавить игрока в точку | Удерживать палец на пустом месте площадки |
| Сменить тип линии / удалить | Тап по линии |
| Удалить несколько объектов | «Ластик» — провести пальцем |

## Разработка

Сайт — обычные HTML/CSS/JS-модули без сборки, папка [`web/`](web/).
Локальный запуск:

```bash
python -m http.server 8765 --directory web
```

При пуше в `main` сайт публикуется на GitHub Pages workflow-ом `.github/workflows/pages.yml`.
После изменения файлов увеличьте `VERSION` в `web/sw.js`, чтобы обновились офлайн-копии на телефонах.

| Файл | Что внутри |
|---|---|
| `web/js/model.js` | Модель данных, переход к следующему шагу, интерполяция анимации |
| `web/js/geometry.js` | Размеры площадки, перевод метров в пиксели, операции с линиями |
| `web/js/render.js` | Отрисовка площадки, линий и фишек на Canvas |
| `web/js/editor.js` | Редактор: инструменты, жесты, шаги, варианты, история |
| `web/js/app.js` | Список тактик, справочник, маршрутизация |
| `web/js/playbook.js` | Готовые комбинации |
| `web/js/storage.js`, `share.js` | Хранение, ссылки и файлы для обмена |
| `web/js/exporter.js` | Сохранение картинкой |
| `web/sw.js` | Офлайн-работа |

## Android-версия (нативная)

В корне лежит также нативное Android-приложение (Kotlin, Jetpack Compose) с теми же возможностями —
папка [`app/`](app/). Сборка: `./gradlew assembleDebug` (нужны JDK 17 и Android SDK 37),
APK появится в `app/build/outputs/apk/debug/`.
